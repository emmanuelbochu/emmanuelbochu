### Projets

#### [Analyseur d'aliments](https://github.com/emmanuelbochu/analyseur-aliments)

Trouve des alternatives avec un meilleur Nutri-Score à partir d'un code-barres, via l'API Open Food Facts. JavaScript orienté objet, webpack, Babel. BUT 2e année, seul.

#### [Route Manager](https://github.com/emmanuelbochu/route-manager)

Calcul d'itinéraires entre villes de France avec l'algorithme de Floyd-Warshall. C++17, interface Qt 6. BUT 1re année, seul.

#### [Gestion des étudiants et des absences](https://github.com/emmanuelbochu/gestion-etudiants-absences)

Gestion d'étudiants et d'absences avec import et export JSON et XML. C++17, Qt 6. BUT 1re année, à deux.

#### [Bibliothèque numérique](https://github.com/emmanuelbochu/bibliotheque-numerique)

Gestionnaire de bibliothèque en ligne de commande : consultation, recherche, import CSV, export HTML. C++17, STL, Makefile. BUT 1re année, seul.

#### [Hexis](https://github.com/emmanuelbochu/hexis)

App iOS de musculation et d'alimentation, conçue et dirigée par moi, code généré par IA. Swift, SwiftUI, SwiftData.

#### [Portfolio 3D](https://emmanuel-bochu.vercel.app)

Mon portfolio, site statique HTML, CSS et JavaScript avec une scène 3D en Three.js, déployé sur Vercel.
